# Profile contribution checklist

Before sharing a profile collection:

1. Test every mapped control on the listed mouse model and connection mode.
2. Export the profile collection from NagaController and verify that importing it preserves existing profiles.
3. Use a descriptive filename under `profiles/community/`.
4. State the intended use, tested hardware, and any controls that need **Learn Hardware Trigger…**.
5. Exclude personal data, local file paths, application-specific secrets, and shell-command actions.

Open a pull request with the JSON file and a short README entry describing the collection.
